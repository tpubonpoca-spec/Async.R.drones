# Async.reality

Сборка Z-City с поддержкой FPV дронов LVS.

## Что исправлено:
- **Камера FPV**: Вид от 1 лица зафиксирован на носу дрона, не вылезает в текстуры и поворачивается строго вместе с ним.
- **Управление**: Работает нормальное управление мышкой для FPV дронов.
- **Защита оператора**: Игрок на земле больше не умирает от взрыва своего дрона на расстоянии.
- **Оптимизация**: Отключена лишняя автозагрузка из воркшопа.

## Установка:
Закинуть папку `Async.reality` в `garrysmod/addons/`.
