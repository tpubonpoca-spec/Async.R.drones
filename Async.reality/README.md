# Async.reality

Гибридный сборник Z-City с полной поддержкой FPV дронов на базе LVS.

## Что сделано:
- **Совместимость с LVS FPV**: Полная интеграция квадрокоптеров (KVN и др.) с графической системой Z-City.
- **Фиксированная FPV-камера**: Точная привязка вида к носовому объективу 1 к 1 без заглядывания в текстуры.
- **Управление мышкой**: Нативная рулежка LVS без залипаний.
- **Защита от дистанционного взрыва**: Оператор на земле больше не гибнет от детонации дрона у цели.
- **Оптимизация**: Отключена авто-загрузка лишнего контента из Воркшопа.

## Установка:
Положите папку `Async.reality` в `garrysmod/addons/`.
