# zAsync — FPV Drone System for Garry's Mod

Продвинутая система FPV-дронов с наземным операторским терминалом и процедурной интеграцией для Garry's Mod / Z-City.

## 🛰 Особенности системы:
- **Наземное операторство**: Оператор остается физически на земле, полностью уязвим для урона и видят реальное окружающее пространство. FPV-камера транслируется прямо на экран.
- **Терминал управления [F6]**: Строгий военный интерфейс выборки дронов (KVN-1 Камикадзе, KVN-2 FLIR Разведчик, KVN-3 Тяжёлый).
- **Звуковая инициализация BLHeli**: Воспроизведение последовательности стартовых звуков ESC с физической блокировкой управления на 5.4 секунды при запуске.
- **3D2D Пульт Управления**: Нативный Viewmodel геймпада Xbox со встроенными руками и активным FPV-экраном.
- **FLIR Тепловизор**: Переключение режима тепловизора в реальном времени (ПКМ).

## 🎮 Управление:
- **F6** — Открыть/Закрыть операторский терминал
- **ЛКМ** — Спавн / Запуск дрона (на земле) | Подрыв камикадзе (в полёте)
- **ПКМ** — Выбор типа дрона (на земле) | Переключение FLIR (в полёте)
- **R** — Экстренное отключение связи с дроном

## 📦 Установка:
Поместите папку `zAsync` в директорию `garrysmod/addons/`.
