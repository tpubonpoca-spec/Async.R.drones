# Zdrone Project

Сборка Garry's Mod: **Async.reality (Z-City)** + **LVS FPV Drones**.

## Состав сборки:
- **Async.reality**: модифицированный гейммод Z-City со встроенной совместимостью с LVS FPV-дронами.
- **lvs_framework**: исправленный базовый фреймворк LVS с фиксацией камеры и защитой операторов БПЛА.
- **lvs_crocus_remastered**: FPV квадрокоптеры Crocus с защитой от дистанционного взрыва.
- **lvs_kvn_fiber_optic_drone_3698755113**: оптоволоконные FPV-дроны KVN с FPV-камерой.

## Что исправлено:
1. **FPV Камера**: вынесена на передний объектив носа дронов (`Vector(15, 0, 4)`), жестко зафиксирована 1 к 1 на корпусе без заглядывания в текстуры.
2. **Рулежка мыши**: включена нативная рулежка LVS для FPV квадрокоптеров.
3. **Защита оператора**: оператор на земле больше не гибнет при дистанционном подрыве дрона у цели.
4. **Контент**: вырезаны лишние загрузки Workshop.

## Установка:
Скопируйте все 4 папки в `garrysmod/addons/`.
