# zAsync

Единый монолитный аддон **zAsync** — модифицированная сборка Z-City со встроенной полной поддержкой FPV дронов LVS.

## Состав единого аддона:
- **zAsync Core (гейммод)**: Полная графическая и физическая система Z-City.
- **LVS Framework**: Встроенный фреймворк LVS с зафиксированной FPV-камерой и защитой операторов от дистанционного взрыва.
- **KVN FPV Drones**: Встроенный комплект оптоволоконных FPV-дронов KVN.

## Что исправлено:
- **Камера FPV**: Вид от 1 лица зафиксирован 1 к 1 на носу дрона, без заглядывания в текстуры и без улетов за карту.
- **Управление**: Работает нормальная рулежка мышкой для FPV дронов.
- **Защита оператора**: Оператор не умирает от дистанционного взрыва собственного дрона у цели.
- **Оптимизация**: Вырезан лишний автоскачиваемый контент Воркшопа.

## Требования / Зависимости:
- **SW Bombs V3** — обязателен для пульта управления (станции НСУ `sw_uav_control`), спавнящегося рядом с дроном.

## Установка:
Скопируйте папку `zAsync` в `garrysmod/addons/`.

## Отладка:
Для включения экранного окна отладки введите в консоли: `async_drone_debug 1`.
